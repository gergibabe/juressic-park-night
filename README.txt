JURASSIC NIGHT — INTERACTIVE INVITATION

Open index.html in a browser, or upload the entire folder to a static host.
Keep the assets folder beside index.html.

Interaction:
1. Tap/click postcard.
2. VHS slides upward from inside the postcard.
3. Tap/click VHS to open the invitation details.

To publish:
- GitHub Pages: upload the folder contents to a repository and enable Pages.
- Netlify/Vercel: drag/drop or deploy the folder.

The page uses no external libraries, fonts, or tracking.
